<Update label="September 30, 2026" description="Release 2026.09.2" tags={["Platform", "Evaluations", "Campaigns"]} rss={{ title: "Access request approvals, evaluation sources, click-to-call dashboard" }}>

## Approve or reject access requests

When someone asks to join your company, admins now review the request in **Settings → Users**. To approve it, assign the person a workspace, team, and role in one step, so they start with the right access from day one. Rejected requests are closed without creating an account.

### Evaluations

**Evaluation sources**: Choose which calls an evaluation scores: calls handled by your AI voice agents, recordings from click-to-call, or recordings you upload. Evaluation results can now be filtered too.

**Typed analysis outputs**: Analysis outputs now have a type, including a new boolean type for yes/no answers. That makes results easier to filter and send to other tools.

### Calls and agents

**Click-to-call dashboard**: Click-to-call now has its own dashboard showing click-to-call activity on its own.

**Web call metadata**: Pass custom metadata when you start a web call, so the call can be tied back to the user, order, or session that started it.

**Video agent termination message**: Set the message a video agent says when it ends a conversation.

</Update>

<Update label="September 15, 2026" description="Release 2026.09.1" tags={["Voice AI", "Integrations", "Campaigns"]} rss={{ title: "Model deprecation notices, tool filler words, Integrations page" }}>

## Model deprecation notices

When a voice agent, chatbot, AI assistant, or evaluation uses a model the provider is retiring, its detail page now warns you, showing either the date the model will be deprecated or the date it already was. You can switch models before a retirement affects live conversations, instead of finding out when calls fail.

## Filler words while tools run

When an agent calls a tool or custom action, you can now set what it says out loud while it waits, for example *"Let me check that for you…"*. Callers aren't left in silence during lookups, which makes conversations feel more natural and cuts hang-ups. Filler messages have a character limit to keep them short.

## Integrations in Settings

A new **Settings → Integrations** page lists every connected integration in one place. Review what's connected and remove integrations you no longer use.

### Campaigns

**Bulk knowledge base management**: Add or remove knowledge bases across several campaigns at once, instead of editing each campaign separately.

### Voice AI

**Tools used**: Agent detail pages now show which tools the agent used, so you can confirm integrations are being called as expected.

</Update>
