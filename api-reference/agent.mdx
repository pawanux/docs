title: Overview
description: Create and manage agents across Voice, Chat, Telephony, and General types
---

The Agent API is the general-purpose way to create and manage agents in UnleashX. Unlike [Create Voice Agent](/api-reference/voice-ai/create-voice-agent), which only creates voice agents, this API supports all agent types through a single endpoint:

- **Voice** (`agent_type: 1`)
- **Chat** (`agent_type: 2`)
- **Telephony** (`agent_type: 3`)
- **General** (`agent_type: 4`)

Use it to configure an agent's basic details, prompt, voice/transcriber settings, knowledge base, calling numbers, denied words, dispositions, guardrails, and metadata — all in a single `multipart/form-data` request.
