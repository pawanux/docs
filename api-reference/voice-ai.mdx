title: Voice AI

---

The Voice AI APIs let you build, launch, and analyze AI-powered outbound and inbound voice calling. Create voice agents, target them at audiences through campaigns, trigger one-off calls, and evaluate call quality from a single set of endpoints.

<CardGroup cols={2}>
  <Card title="Voice" icon="microphone-lines">
    Create and manage voice agents, phone numbers, voices, and call logs.
  </Card>
  <Card title="Campaigns" icon="bullhorn">
    Run outbound calling campaigns against an audience or segment.
  </Card>
  <Card title="Audience" icon="users">
    Build contact lists, segments, and input variables for your campaigns.
  </Card>
  <Card title="Click to Call" icon="phone-arrow-up-right">
    Trigger a call on demand and track its live status.
  </Card>
</CardGroup>

## Authentication

All Voice AI endpoints require a valid API token. See [Authentication](/api-reference/authentication) for how to generate and pass your token.
