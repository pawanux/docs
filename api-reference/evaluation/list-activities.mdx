title: List Evaluation Activities

Paginated per-call evaluation results. The response contains only `datalist` and `pagination` (no table `headers`).

## Endpoint

**GET** `/evaluation/activities`

**Authentication:** API token in the `token` header.

## Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `eval_id` | number | No | Filter by evaluation |
| `agent` | string | No | Comma-separated agent IDs |
| `call_id` | string | No | Filter by call ID |
| `status` | string | No | Comma-separated activity statuses |
| `filter` | string | No | Date filter (e.g. `today`, `week`) |
| `from` | string | No | Start date |
| `to` | string | No | End date |
| `page` | number | No | Page number (default `1`) |
| `limit` | number | No | Records per page (default `10`) |

## Response

```json
{
  "message": "Call Evaluation activities fetched successfully",
  "datalist": [],
  "pagination": {}
}
```
