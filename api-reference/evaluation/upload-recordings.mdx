Upload a recording file for evaluation. The response is streamed as server-sent events so you can follow the upload progress.

## Endpoint

**POST** `/evaluation/upload-recordings`

**Content-Type:** `multipart/form-data`
**Authentication:** API token in the `token` header.

## Form Data

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `file` | file | Yes | Recording file. Allowed types: zip, mp3, wav. |

## Response

The response is a `text/event-stream`. Each event is a JSON object:

```json
{ "status": "started", "percentage": 0, "message": "Upload started" }
{ "status": "processing", "percentage": 50, "message": "File uploaded successfully", "totalRecordings": 1 }
{ "status": "completed", "percentage": 100, "message": "Recordings uploaded successfully", "summary": {} }
```

On failure an event with `"status": "error"` and a `message` is sent.

## Error Cases

| Error | Cause |
|-------|-------|
| `No files uploaded` | The request has no `file` |
| `Invalid file type. Allowed: zip, mp3, wav` | Unsupported file type |

## Example cURL

```bash
curl -N -X POST https://dev.tryunleashx.com/api/v1/global/evaluation/upload-recordings \
  -H "token: <api_key>" \
  -F "file=@recordings.zip"
```
