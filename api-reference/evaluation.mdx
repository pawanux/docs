---
title: Evaluation
description: Configure evaluations, criteria and read evaluation results
---

Evaluation APIs let you create and manage call evaluations, their criteria, and read per-call results and dashboard data.

All endpoints live under `/api/v1/global/evaluation/*` and authenticate with your API token in the `token` header. They run the same logic as the in-app evaluation APIs. List and report endpoints return only data and `pagination` (no UI table `headers`).

| Endpoint | Method | Path |
|----------|--------|------|
| [Create Evaluation](/api-reference/evaluation/create-config) | POST | `/evaluation/create-update-config` |
| [Update Evaluation](/api-reference/evaluation/update-config) | POST | `/evaluation/create-update-config` |
| [Generate Evaluation Webhook URL](/api-reference/evaluation/generate-webhook-url) | POST | `/evaluation/generate-webhook-url` |
| [Upload Recordings](/api-reference/evaluation/upload-recordings) | POST | `/evaluation/upload-recordings` |
| [List Evaluations](/api-reference/evaluation/list-evaluations) | GET | `/evaluation/list` |
| [Evaluation Details](/api-reference/evaluation/evaluation-details) | GET | `/evaluation/details` |
| [List Evaluation Activities](/api-reference/evaluation/list-activities) | GET | `/evaluation/activities` |
| [Export Evaluation Activities](/api-reference/evaluation/export-activities) | GET | `/evaluation/activities/export` |
| [Evaluation Dashboard](/api-reference/evaluation/dashboard) | GET | `/evaluation/dashboard` |
| [Create Evaluation Criteria](/api-reference/evaluation/create-criteria) | POST | `/evaluation/criteria/create-update` |
| [Update Evaluation Criteria](/api-reference/evaluation/update-criteria) | POST | `/evaluation/criteria/create-update` |
| [List Evaluation Criteria](/api-reference/evaluation/list-criteria) | POST | `/evaluation/criteria/list` |
